# Remote Companion for Antigravity — Releases

Official release distribution hub for **Remote Companion for Antigravity** (Android Companion App + Windows PC Bridge).

> **Note:** This repository hosts compiled releases, update metadata (`version.json`), and documentation only. Source code is maintained privately.

## Components
- **Android Companion App:** Distributed via Google Play (zero sideloading, automatic updates).
- **Windows PC Bridge:** Lightweight local companion service running on your Windows PC over your private Tailscale network, with automatic update checks from this repository.
